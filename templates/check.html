Point WSJT-X here. File → Settings → Reporting. Either box works — use whichever one you have free.
  1. Secondary UDP Server — tick Enable logged contact ADIF broadcast, then this machine's address and port 2333.
    Usually free, because the box above it is taken by JTAlert or GridTracker. Sends only completed contacts — so you appear here after your first contact, not before.
  2. UDP Server — the same address, port 2237.
    Only if nothing else is using it. You appear within about fifteen seconds without working anybody, because WSJT-X announces itself on this one.
Not sure? Use the secondary, log one contact with anybody, and check this page.
